# How this workspace is used

- Each feature's `spec.md` (in `spec/features/<slug>/`) is the source of truth.
- `product.md`, `dashboard.md`, `analyze-product.md`, and `view.html` are generated.
  Run `node scripts/assemble.mjs`, `node scripts/dashboard.mjs`, and `node scripts/view.mjs`.
- `constitution.md` and `product-global.md` are main-branch-only. Change them in a
  dedicated PR, never inside a feature branch.
- Start a new feature with `/spec-flow:feature`, or use `/spec-flow:express` for a
  quick prototype pass.
